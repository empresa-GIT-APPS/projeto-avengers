# 🎮 Git Pixel - Projeto Avengers (Arquivado)

> **Status do Projeto:** 🛑 Descontinuado / Arquivado  
> **Organização:** Git Pixel  

---

## 📌 Sobre o Projeto
O **Projeto Avengers** foi a iniciativa inaugural da **Git Pixel**, idealizada com o objetivo de desenvolver um jogo de combate/PvP inspirado no universo dos Vingadores. O repositório contém a documentação e os registros das etapas de planejamento e modelagem do produto antes do seu arquivamento definitivo.

---

## 🔄 Evolução do Conceito

* **Fase 1: Guerra Infinita (Conceito Inicial)**
  * **Proposta:** Jogo PvP de grande escala baseado nos eventos do filme *Vingadores: Guerra Infinita*.
  * **Foco:** Múltiplos personagens, habilidades complexas e sistemas de combate avançados.

* **Fase 2: Guerra Civil (Ajuste de Escopo)**
  * **Proposta:** Simplificação do projeto para uma temática baseada em *Vingadores: Guerra Civil*.
  * **Mecânica:** Gameplay PvP local focado em 2 jogadores compartilhando o mesmo computador (mesmo teclado/periféricos).
  * **Objetivo:** Tentar viabilizar a entrega reduzindo a complexidade de rede e backend.

---

## 🛑 Motivo do Arquivamento (Post-Mortem)

A decisão de descontinuar o desenvolvimento do jogo foi tomada com base nos seguintes fatores críticos levantados na gestão do produto:

* **Complexidade Elevada:** A criação do sistema de movimentação, colisão, animação e balanceamento para um jogo de luta demandava recursos técnicos além do viável para a primeira entrega.
* **Prazo Restrito:** O tempo limite de desenvolvimento (poucos meses) era incompatível com o ciclo de vida necessário para lançar um jogo funcional do gênero.
* **Tamanho da Equipe:** O time reduzido inviabilizou a distribuição equilibrada de demandas entre programação, arte e testes de qualidade.

## 🎨 Entregáveis e Estrutura Criada

Embora o desenvolvimento do jogo tenha sido interrompido, os seguintes ativos de marca e gestão foram consolidados durante o período:
